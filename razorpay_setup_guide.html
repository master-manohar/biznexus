🔑 Razorpay API Key Setup Guide

Follow these steps while your Razorpay dashboard is open. Takes about 3 minutes.

STEP 1

🌐 Open Razorpay Dashboard

Go to the Razorpay dashboard and make sure you are logged in:

→ Open dashboard.razorpay.com
✅ Make sure your account is KYC verified and Live mode is activated. If not, you'll only have Test keys.
STEP 2

⚙️ Navigate to API Keys Section

In the Razorpay dashboard, click through this path:

⚙️ Settings → API Keys → Select Mode: Live
⚠️ There are TWO modes — Test Mode (for testing) and Live Mode (real payments). Always use Live Mode for production.
STEP 3

🔄 Generate API Keys

  1. Click "Generate Key" (or "Regenerate" if you've done it before)
  2. Razorpay will show you two values:
Key ID (starts with rzp_live_...) rzp_live_XXXXXXXXXXXXXXXX

Key Secret (shown ONCE — copy immediately!) XXXXXXXXXXXXXXXXXXXXXXXX
⚠️ The Key Secret is shown only once. Copy it immediately and save it somewhere safe. If you miss it, you'll need to regenerate.
STEP 4

📋 Paste Your Keys Below (for reference)

📦 Optional — Razorpay Plan IDs

If you want subscriptions (auto-recurring monthly) instead of one-time payments, you'll also need to create Plans in Razorpay:

💳 Subscriptions → Plans → Create Plan

Each plan will give you a plan_XXXXXX ID. Tell us if you want subscriptions or one-time payments — we'll build accordingly.
